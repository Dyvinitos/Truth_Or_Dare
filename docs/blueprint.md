# **App Name**: Daredevil Truths

## Core Features:

- Player Setup: Set up a menu to specify the number and names of players.
- Turn Selection: Offer a menu to select the number of turns (20, 50, or 70).
- Live Score Tracking: Display the scoresheet at all times to show each player's progress.
- Truth/Dare Management: Include a button to manage the truth and dare list with options to delete items.
- Custom Submission Form: Add a button leading to a form where users can add new truths or dares.
- Interactive Game Cards: Cards that include truths and dares for the user.
- End Game Scoresheet: Final scoresheet to show who completed the most truths and dares.

## Style Guidelines:

- Primary color: A vibrant purple (#A020F0) to evoke a sense of playful mystery.
- Background color: A light purple (#E6D7F2), very desaturated, for a soft, clean look.
- Accent color: A brighter violet-blue (#6F2DFF), analogous to the primary, for interactive elements.
- Font pairing: 'Playfair' (serif) for headlines and titles, 'PT Sans' (sans-serif) for body text to combine elegance with readability.
- Use outlined icons for a clean and modern look, with brighter fills upon interaction.
- Use a card-based layout for displaying truths and dares, with clear call-to-action buttons.
- Use subtle fade-in and slide-up animations when new cards are loaded, providing a dynamic user experience.
